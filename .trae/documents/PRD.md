# 电池健康 App Web 展示版 V4.4.6 - 产品需求文档 (PRD)

## 1. 项目背景

### 1.1 起源
本项目来源于 `BatteryHealthApp` Android 原生应用（包名 `com.batteryhealth.app`，最新版本 4.4.6）。该 Android 应用是一款专业的电池健康监测工具，提供电池健康、充电功率、性能分析、电池江湖、配置查询等五大维度的实时数据。

### 1.2 目标
将 Android 原生应用 V4.4.6 的功能界面以 Web 形式 1:1 复刻展示，生成可在浏览器中直接打开的"产品展示页/UI 展示页"，用于：
- 产品演示与宣传
- 用户在不安装 APK 的情况下预览全部功能
- 设计参考与团队评审

### 1.3 目标用户
- 潜在用户：希望在不下载应用的情况下预览产品 UI
- 设计与产品团队：评审界面与交互
- 营销/运营：嵌入官网或分享链接

## 2. 范围

### 2.1 In Scope
- 完整复刻 Android 应用 V4.4.6 5 大 Tab 的视觉与结构
- 真实模拟数据（健康度、CPU、内存、帧率、功率等可周期性变化）
- 移动端优先的响应式布局（同时支持桌面端预览）
- 单文件 HTML，直接打开即可运行

### 2.2 Out of Scope
- 真实读取 Android 设备数据
- 真实充电、后台监测等系统级能力
- 多语言切换（仅中文，与 Android 端一致）
- 用户账号、云端同步

## 3. 信息架构

应用由 **底部导航 5 Tab** 构成，遵循 iOS 2026 风格：

| # | Tab 名称 | 关键内容 |
|---|---------|---------|
| 0 | 电池健康 | 健康度大数字 + 等级 + 进度条；详细信息（容量/循环/温度/电压/来源/技术）；周报/月报按钮；趋势入口 |
| 1 | 充电功率 | 当前充电功率大数字 + 类型徽章；充电详情（电压/电流/阶段/电量/预计充满）；充电历史 |
| 2 | 电池江湖 | 电池养护小贴士卡片；社区入口按钮 |
| 3 | 配置查询 | 设备名称、Android 版本、处理器、内存、存储、屏幕、激活日期、使用天数；Bugreport 指南入口 |
| 4 | 性能分析 | CPU/内存/存储使用率卡片；性能评分；GPU 信息；实时帧率 + 卡顿检测 |

## 4. 用户体验

### 4.1 设计风格
- **iOS 2026 设计语言**：半透明毛玻璃卡片（liquid glass）、大号数字、SF Pro 字体族
- **配色**：浅色模式为主，强调色使用 iOS 系统色（绿/蓝/橙/青）
- **运动**：进入页面 fadeIn；进度条过渡动画；卡片微动效

### 4.2 关键交互
- 底部 5 标签导航（与 Android V4.4.6 一致）
- 切换 Tab 时页面内容区域做 fadeIn 动画
- 状态栏显示实时时间
- 模拟数据每 3 秒刷新一次

## 5. 验收标准
- 单文件 HTML 可直接在浏览器打开
- 桌面端宽度下显示手机框架预览；移动端宽度下占满屏幕
- 5 个 Tab 全部可点击切换，无报错
- 模拟数据正确显示并自动更新
- 周报/月报弹窗、Bugreport 弹窗正常弹出
