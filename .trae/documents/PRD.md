# 电池健康 App Web 展示版 - 产品需求文档 (PRD)

## 1. 项目背景

### 1.1 起源
本项目来源于 `BatteryHealthApp` Android 原生应用（包名 `com.batteryhealth.app`，最新版本 4.0.1）。该 Android 应用是一款专业的电池健康监测工具，提供电池健康度、设备配置、性能、续航、趋势、充电功率等六大维度的实时数据。

### 1.2 目标
将 Android 原生应用的功能界面以 Web 形式 1:1 复刻展示，生成可在浏览器中直接打开的"产品展示页/UI 展示页"，用于：
- 产品演示与宣传
- 用户在不安装 APK 的情况下预览全部功能
- 设计参考与团队评审

### 1.3 目标用户
- 潜在用户：希望在不下载应用的情况下预览产品 UI
- 设计与产品团队：评审界面与交互
- 营销/运营：嵌入官网或分享链接

## 2. 范围

### 2.1 In Scope
- 完整复刻 Android 应用 6 大 Tab 的视觉与结构
- 真实模拟数据（健康度、CPU、内存、功率等可周期性变化）
- 移动端优先的响应式布局（同时支持桌面端预览）
- 一次构建、直接静态打开 `index.html` 即可运行（无构建步骤）

### 2.2 Out of Scope
- 真实读取 Android 设备数据
- 真实充电、后台监测等系统级能力
- 多语言切换（仅中文，与 Android 端一致）
- 用户账号、云端同步

## 3. 信息架构

应用由 **底部导航 6 Tab** 构成，遵循 iOS 2026 风格：

| # | Tab 名称 | 关键内容 |
|---|---------|---------|
| 0 | 电池健康 | 健康度大数字 + 等级 + 状态 + 进度条；详细信息列表（容量/循环/温度/电压/来源/技术） |
| 1 | 设备配置 | 设备名称、Android 版本、处理器、内存、存储、屏幕、激活日期、使用天数 |
| 2 | 性能 | CPU 使用率卡片（数值 + 进度条）、内存使用率卡片（数值 + 进度条） |
| 3 | 续航 | 预计续航时间大数字；电池使用详情（当前电量/放电速率/充电状态/温度/预计充满） |
| 4 | 趋势 | 健康度变化趋势折线图（6 个月）；统计数据网格（初始/当前/总衰减/月均衰减） |
| 5 | 充电 | 当前充电功率大数字 + 类型徽章；充电详情（电压/电流/阶段/电量/预计充满）；今日充电历史 |

## 4. 用户体验

### 4.1 设计风格
- **iOS 2026 设计语言**：圆角 20px、大号数字、SF Pro 字体族、半透明卡片、模糊毛玻璃底栏
- **配色**：浅色模式为主（与 Android 端一致），强调色使用 iOS 系统色（绿/蓝/橙/紫/青）
- **运动**：进入页面 fadeIn；进度条过渡 1s；充电徽章脉冲；功率数字每 3 秒微动

### 4.2 关键交互
- 底部 5 标签 + 健康 Tab 共 6 项（与 Android `MainActivity` 中 `getItemCount() = 6` 一致）
- 切换 Tab 时页面内容区域做 fadeIn 动画
- 状态栏显示实时时间
- 模拟数据每 3 秒刷新一次（CPU/内存/功率）

## 5. 验收标准
- `battery-health-web/index.html` 单文件可直接在浏览器打开
- 桌面端宽度下显示手机框架预览；移动端宽度下占满屏幕
- 6 个 Tab 全部可点击切换，无报错
- 模拟数据正确显示并自动更新
