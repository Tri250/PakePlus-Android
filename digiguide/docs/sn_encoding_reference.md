## 2. Samsung 三星

### 格式结构（新格式）
```
位置: 倒数第7位 = 年份
      倒数第6位 = 月份
```

### 年份编码
| 字符 | 年份 |
|------|------|
| R | 2023 |
| S | 2024 |
| T | 2025 |
| U | 2026 |
| V | 2027 |
| W | 2028 |

### 月份编码
| 字符 | 月份 |
|------|------|
| 1-9 | 1-9月 |
| A | 10月 |
| B | 11月 |
| C | 12月 |

**示例**: `R5CR70H1N4` → 倒数第7位=R(2023)，倒数第6位=7(7月)

## 3. Huawei 华为

### 格式结构
```
位置: 6-7位 = 年份后两位
      8-9位 = 周次
示例: XXXXXX 23 15 XXXXX → 2023年第15周
```

---

## 4. Xiaomi 小米

### 格式结构
```
多种格式，需根据长度和前缀判断：
- IMEI格式：提取生产信息
- 自定义格式：第3-4位含年份信息
```

---

## 5. OPPO

### 格式结构
```
位置: 第4-5位 = 年份+月份编码
需要查表解码
```

---

## 6. vivo

### 格式结构
```
位置: 第5-6位 = 年份信息
      第7-8位 = 周次或月份
```

---

## 7. Honor 荣耀

### 格式结构
```
与华为类似，继承华为编码规则
位置: 6-7位 = 年份后两位
      8-9位 = 周次
```

---

## 8. Lenovo 联想（PC）

### 格式结构
```
ThinkPad系列：
位置: 前4位 = 机型代码
      第5位 = 年份（需查表）
```

---

## 9. HP 惠普（PC）

### 格式结构
```
位置: 第3-4位 = 生产年份和地区
      后续位 = 生产周次
```

---

## 10. ASUS 华硕（PC）

### 格式结构
```
位置: 第2位 = 年份代码
      第3位 = 月份代码
```

---

## 11. Dell 戴尔（PC）

### 格式结构
```
服务标签：5-7位字母数字组合
快速服务代码：数字编码
需通过Dell官方API查询
```

---

## 12. Apple Mac（电脑）

### 格式结构
```
与iPhone类似但长度可能不同：
- 12位格式：同iPhone规则
- 其他格式：需特殊处理
```

## 解码优先级

1. **容量保持率** - 最基础指标，权重35%
2. **循环衰减** - 直接反映使用强度，权重30%
3. **内阻增长** - 电池老化核心指标，权重15%
4. **温度老化** - 环境因素影响，权重10%
5. **充电损伤** - 使用习惯影响，权重10%

---

## 注意事项

1. 所有解码算法均为**确定性查表**，不使用随机值
2. 无法识别的SN返回 `PARTIAL` 或 `FAILED` 状态
3. 品牌官方API查询作为补充数据源
4. 生产日期为推算值，可能与实际有偏差
